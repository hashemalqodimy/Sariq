# تطبيق أمان فون (Aman Phone) 🇾🇪
**المنصة الوطنية للبلاغات وحماية الهواتف المسروقة - الجمهورية اليمنية**

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3**، يهدف لمكافحة سرقة الهواتف الذكية وحماية المواطنين ومحلات الجوالات في كافة المحافظات اليمنية الـ 22.

---

### ✨ المميزات الرئيسية
- 📋 **تسجيل بلاغات السرقة والفقدان:** تعميم فوري بمواصفات الهاتف الدقيقة (الماركة، الموديل، IMEI1، IMEI2، الرقم التسلسلي، اللون والمحافظة والشارع).
- 🚨 **نظام التنبيهات الفوري (Instant Broadcast):** بث تنبيه عاجل وإشعار نظام أندرويد حقيقي لجميع مستخدمي المنصة ومحلات الهواتف فور تسجيل أي بلاغ.
- 🔍 **أداة الفحص الأمني للـ IMEI:** فحص أي هاتف مستعمل قبل شرائه من خلال الكود `*#06#` لمعرفة ما إذا كان مسجلاً كمسروق في أي محافظة يمنية.
- 💾 **قاعدة بيانات محلية (Room Database):** دعم العمل دون اتصال بالإنترنت (Offline-first) مع حفظ دائم للبلاغات والفحوصات.
- 🇾🇪 **تغطية شاملة للمحافظات اليمنية:** تصنيفات مخصصة للمحافظات الـ 22، وأرقام الطوارئ، ودعم أرقام الاتصال المحلية.
