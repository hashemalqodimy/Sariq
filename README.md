# تطبيق أمان فون (Aman Phone) 🇾🇪
**المنصة الوطنية للبلاغات وحماية الهواتف المسروقة - الجمهورية اليمنية**

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** وفق أحدث معايير **Material Design 3**، يهدف لمكافحة سرقة الهواتف الذكية وحماية المواطنين ومحلات الجوالات في كافة المحافظات اليمنية الـ 22.

---

### ✨ المميزات الرئيسية
- 📋 **تسجيل بلاغات السرقة والفقدان:** تعميم فوري بمواصفات الهاتف الدقيقة (الماركة، الموديل، IMEI1، IMEI2، الرقم التسلسلي، اللون والمحافظة والشارع).
- 🚨 **نظام التنبيهات الفوري (Instant Broadcast):** بث تنبيه عاجل وإشعار نظام أندرويد حقيقي لجميع مستخدمي المنصة ومحلات الهواتف فور تسجيل أي بلاغ.
- 🔍 **أداة الفحص الأمني للـ IMEI:** فحص أي هاتف مستعمل قبل شرائه من خلال الكود `*#06#` لمعرفة ما إذا كان مسجلاً كمسروق في أي محافظة يمنية.
- 💾 **قاعدة بيانات محلية (Room Database):** دعم العمل دون اتصال بالإنترنت (Offline-first) مع حفظ دائم للبلاغات والفحوصات.
- 🇾🇪 **تغطية شاملة للمحافظات اليمنية:** تصنيفات مخصصة للمحافظات الـ 22، وأرقام الطوارئ، ودعم أرقام الاتصال المحلية.

---

### 🛠️ البناء محلياً
```bash
# يتطلب JDK 17 و Android SDK (compileSdk 36) و Gradle 9.3+
touch .env                      # مفاتيح اختيارية (انظر .env.example)
gradle testDebugUnitTest        # اختبارات الوحدة
gradle assembleDebug            # ينتج app/build/outputs/apk/debug/app-debug.apk
```
- يتم توليد `debug.keystore` تلقائياً عند أول بناء (الملف مُتجاهَل في Git).
- لتفعيل Firebase (المصادقة، Firestore، FCM) ضع `google-services.json` داخل مجلد `app/` — الملف مُتجاهَل في Git ولا يجب رفعه.
- لتوقيع نسخة الإصدار عرّف متغيرات البيئة `KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.

### 🔐 ملاحظات أمنية
- صلاحيات المشرف تُمنح فقط لحساب مُوثّق عبر Google / Firebase Auth، ولا يمكن الحصول عليها بحساب محلي دون اتصال.
- كلمات مرور الحسابات المحلية (وضع عدم الاتصال) تُخزَّن كتجزئة PBKDF2 مملّحة ولا تُحفظ نصاً صريحاً.
- النسخ الاحتياطي التلقائي لقاعدة البيانات معطّل (`allowBackup=false`).

### 📥 الحصول على ملف الـ APK
عند رفع هذا المشروع إلى **GitHub**:
1. يتولى نظام **GitHub Actions** المدمج بناء ملف الـ APK تلقائياً.
2. يمكنك الانتقال إلى تبويب **Actions** في مستودع GitHub، واختيار أحدث Build، ثم تنزيل ملف `aman-phone-debug-apk` مباشرة وتثبيته على هاتفك.
